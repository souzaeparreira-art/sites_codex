# Code 8734 — Conselheiro Lafaiete

Landing page responsiva para captar solicitações de aulas experimentais de Robótica, Games e Informática.

## Visualizar

Abra `index.html` no navegador ou execute nesta pasta:

```sh
python -m http.server 8734
```

Acesse http://localhost:8734.

## Editar

- `index.html`: conteúdo, endereço e links para Google Maps.
- `style.css`: estilos e layouts para desktop e celular.
- `app.js`: validação do formulário e encaminhamento ao WhatsApp.
- `assets/`: identidade visual fornecida pelo cliente.

WhatsApp: +55 31 98934-9352.
Endereço: R. Mal. Floriano Peixoto, 48 - Sl 01 - Centro, Conselheiro Lafaiete - MG, 36406-000.

O formulário abre o WhatsApp com uma mensagem preenchida; o visitante deve enviá-la para concluir a solicitação. Não há banco de dados nem envio automático. As fontes do Google Fonts precisam de conexão à internet.

Para hospedar em um serviço de sites estáticos, selecione esta pasta como diretório publicado. Não há etapa de build.
